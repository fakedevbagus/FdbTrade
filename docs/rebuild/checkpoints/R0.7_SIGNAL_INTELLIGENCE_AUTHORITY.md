## Outcome

R0.7 makes SQLite authoritative for the registered deterministic signal rule,
evaluation attempts, evidence, canonical decision-support candidates and their
append-only lifecycle. Migration `0006_signal_intelligence` adds five tables
and immutability triggers. The authority reads only through the R0.6 market
authority, so every evaluation re-verifies content-addressed candle bytes and
their metadata before using them.

## Rule and provenance

The initial registered rule is `authoritative-momentum-baseline` logic/config
`1.0.0`. It combines the existing rule-based regime classifier and ATR feature
with aligned 5/20-bar momentum and closing confirmation. A directional result
is built by the canonical signal builder with an ATR invalidation level,
explicit expiry and 2R target. This is a deterministic baseline, not a tuned
claim of edge or empirical win probability.

Every evidence record identifies the dataset id and SHA-256 artifact digest,
provider/source mode, rule/config versions, assessment instant, complete input
window coordinates, regime result, metrics, reason codes and canonical signal
when one exists. Explained `wait` and fail-closed `blocked` are durable outcomes,
not missing rows.

## Quality, freshness and lifecycle

The authority refuses to emit a candidate when the source dataset is
quarantined, gapped, duplicated or stale. Freshness is recalculated from the
latest completed bar at an explicit caller-supplied UTC instant; assessments
cannot backdate the dataset publication assessment. Artifact corruption fails
the run rather than falling back to fixture data.

An emitted candidate receives one `identified` event. Calling lifecycle
advancement at or after canonical expiry appends one `expired` event; repeated
calls are idempotent. No wall clock silently changes business state.

## Recovery and idempotency

Evaluation identity covers dataset, rule versions and assessment instant.
Evidence and terminal run state commit atomically. Recovery returns interrupted
`running` work to `pending`, validates evidence digests, reopens source artifacts
and checks signal identity. Fault tests prove replay both before the terminal
commit and after a committed response is lost. A second compatible assessment
may add evidence but cannot duplicate the same canonical candidate.
