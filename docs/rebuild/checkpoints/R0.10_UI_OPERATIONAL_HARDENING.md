## Outcome

R0.10 reconciles the operator UI with the durable authority established by
R0.6–R0.9 and adds a verified local recovery workflow. Migration
`0009_operational_hardening` adds one append-only operational event stream for
backup, restore and deployment-drill evidence. No trading or provider
authority moved into the UI.

## UI and route reconciliation

`GET /api/operations/overview` is authenticated and read-only. It queries the
authoritative dataset, signal, research, risk/paper, reconciliation, outcome
and operational-event tables. The frontend validates the full response and
shows fixed scope, durable risk latch, status counts, recent lineage and
recovery evidence.

Primary navigation now points to the operational projection, verified
historical datasets, durable risk controls and health. The admin control route
exposes only engage-kill, release-kill and force-state through the R0.9
`RiskPaperAuthority`; health also reads `risk_state_events`. The old
process-local risk store is not used by either production surface. The UI has
no paper-order, live-order or model-promotion action.

## Durable operational evidence

`operational_events` uses contiguous sequence numbers, canonical details and a
SHA-256 event digest. SQLite triggers reject update, delete and sequence gaps.
Only verified backup, restore and local deployment-drill outcomes are recorded.

Backup uses the Node 24 SQLite online-backup API. The referenced artifact set
is derived from the completed database snapshot, then R0.6 market-data and
R0.8 research bytes are copied and re-hashed. The atomic backup directory
contains the database, referenced artifacts and a manifest pinning migrations,
hashes, sizes and safety flags.

Restore verifies the complete manifest before writing and accepts only an
absolute empty target. It then verifies SQLite integrity, foreign keys,
migration ledger and artifact hashes before recording success in the restored
database. The deployment drill performs backup, temporary restore, reopen and
verification without external network or services, then records durable
success in the source database.
