## Outcome

R1.0 establishes one canonical blueprint and staged prompt pack for the next
development horizon. It reconciles the historical M44-M53 plan with the actual
R0.1-R0.12 authority chain and defines 24 small implementation or decision
units from authoritative operator workflows through offline private-beta,
read-only provider integration, macro context and challenger research.

R1.0 changes no runtime, database schema, API, UI, trading rule, provider or
execution behavior.

## Governance

Each R1 unit has an explicit copy-ready prompt, scope boundary, verification
expectation and stop rule. The prompt pack itself is not standing authority:
the operator must explicitly name one unit in each new chat. Completion requires
focused observable evidence, the full zero-skip toolchain gate, authority JSON,
checkpoint, `NEXT.md`, one atomic commit and then a stop.

Provider and macro integrations contain deliberate decision gates. No
implementation prompt is valid until the operator names the exact approved
source. A roadmap change similarly requires a separately authorized
documentation-only amendment.
