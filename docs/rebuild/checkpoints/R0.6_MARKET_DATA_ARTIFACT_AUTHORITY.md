## Outcome

R0.6 makes SQLite the authority for market-data datasets, immutable artifact
locations, ingestion jobs, and the quality/freshness facts recorded at
publication. Migration `0005_market_data_artifacts` adds the three authority
tables and database triggers that reject dataset/artifact mutation, deletion,
terminal job rewriting and job deletion.

Canonical candle bytes are no longer embedded in mutable logical-id JSON files.
They are stored once at a SHA-256 content path below
`<data-root>/artifacts/market-data`. Readers resolve the path only through
SQLite, verify digest and byte count, parse every canonical candle and verify
record count before returning data.

## Scope and source authority

The authority fails closed outside the approved matrix:

- instruments: EURUSD, GBPUSD, USDJPY, USDCHF, AUDUSD, USDCAD and NZDUSD;
- timeframes: 15m, 1h and 4h;
- sources: deterministic local fixture or explicitly confirmed operator-owned
  historical CSV.

XAUUSD, 5m and 1d remain outside R0.6 even though older canonical contracts can
represent them. Fixture ingestion accepts only a provider whose capabilities
declare synthetic data. Historical confirmation preserves explicit license
notes and uses the canonical application SQLite connection. No credentialed or
network provider was selected or called.

## Atomic publication and integrity

Publication serializes canonical candle bytes, checks the manifest digest, and
writes a mode-0600 staging file on the destination filesystem. It fsyncs the
file, renames it to the digest path, fsyncs the containing directory, then
inserts artifact plus dataset metadata in one short `BEGIN IMMEDIATE`
transaction. This ordering prevents a visible dataset row from naming content
that has not been published.

An interruption before the SQLite commit can leave only an unreferenced
immutable blob. Recovery removes incomplete staging files, reports unreferenced
blobs without silently adopting/deleting them, re-hashes all registered
datasets, and moves interrupted running ingestion jobs back to pending.
Replaying a recovered job absorbs the already-published digest and completes
the same durable job; a later duplicate returns the stored dataset without
creating another logical dataset.

## Quality and freshness

Dataset metadata records the measured accepted, quarantined, duplicate and gap
counts and derives `accepted`, `quarantined` or `gapped` quality state. The
freshness assessment has no hidden wall-clock dependency: its caller supplies
the UTC assessment instant, and the stored state is fresh through two timeframe
durations after the latest completed candle. Artifact corruption never turns
into an empty or fixture fallback; load fails closed and recovery reports the
dataset id as corrupt.
