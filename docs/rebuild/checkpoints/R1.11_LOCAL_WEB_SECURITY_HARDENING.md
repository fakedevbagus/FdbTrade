## Threat review and outcome

The bounded local threat model covers cross-site mutation attempts, LAN/non-loopback
targets, repeated credential guessing, stolen superseded sessions, password
rotation, sensitive local file disclosure, browser embedding/MIME confusion and
secret-bearing error/log data. The application remains private and single-user.

## Closed authority

The central API wrapper now enforces loopback target and mutation-origin checks,
hardened response headers and recursive secret-detail redaction. Login throttling
uses only a hashed normalized-user key. Successful login atomically rotates the
single active session; password provisioning revokes all sessions. Restart tests
prove only the rotated durable token survives. Permission tests prove 0700 data
directories and 0600 SQLite files.

## Preserved boundaries

No LAN/remote exposure, OAuth, cloud identity, provider credential, external
network call, trading behavior, migration, scheduler or M48 wiring was added.
Twelve migrations and ten M48 files (55,941 bytes) remain intact.
